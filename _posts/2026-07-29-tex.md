## 技術概要とか

以下AIくんにどうやったか書いてもらった。

Jekyll と Minima テーマの標準状態では、Markdown に TeX を書いても数式としては表示されない。そのため、ブラウザ側で数式を描画してくれる **MathJax** を追加した。

具体的には、Minima テーマの `head.html` をプロジェクト側の `_includes/head.html` として上書きし、`<head>` の中で MathJax を読み込むようにした。

```html
<script>
  MathJax = {
    tex: {
      inlineMath: [['$', '$'], ['\\(', '\\)']],
      displayMath: [['$$', '$$'], ['\\[', '\\]']]
    }
  };
</script>
<script defer src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>
```

これで記事中にインライン数式なら `$E = mc^2$`、別行立ての数式なら次のように書けるようになった。

```md
$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$
```

なお、`$` を普通のドル記号として表示したいときは、`\$` のようにエスケープする必要がある。
